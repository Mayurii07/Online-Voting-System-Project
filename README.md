# Online Voting System 🗳️

Desktop Java Swing application for simple online voting.

## Features
- Voter registration with unique 10-digit ID (max 10 voters)
- Vote for Party A, B, or C
- Real-time validation & feedback
- Modern UI: Nimbus theme, Segoe UI fonts, progress bars, hover effects
- View results with % charts & leader

## Modern UI (main_page_modern.java)
- Card layouts for form/results
- Inline status, field highlighting
- Colored progress bars, emojis
- Responsive, animated buttons

## Quick Start
```bash
java main_page_modern
```
