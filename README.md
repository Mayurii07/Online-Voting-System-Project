# 🌟 Online Voting System - Secure Desktop Voting Platform

**Modern Java Swing app for fraud-proof voting with real-time results and visual progress tracking!**

[![Java](https://img.shields.io/badge/Java-007396?style=for-the-badge&logo=java&logoColor=white)](https://java.com/)
[![Swing](https://img.shields.io/badge/Swing-ED8B00?style=for-the-badge&logo=java&logoColor=white)](https://docs.oracle.com/javase/tutorial/uiswing/)

## ✨ Features

### 🗳️ **Voting Interface**
- Unique voter ID validation (10 digits, max 10 voters)
- Party selection (A, B, C)
- Real-time status feedback

### 📊 **Results Dashboard**
- Progress bars for vote percentages
- Live leader determination
- Tie detection with emojis

### 🎨 **Modern UI**
- Nimbus theme & Segoe UI fonts
- Hover animations & focus glows
- Card layouts & responsive design

